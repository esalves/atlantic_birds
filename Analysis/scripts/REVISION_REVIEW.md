# Revision review — independent check of the 2026-09-09 revision session

Reviewer pass over every file created or modified by agents P0–P7 (from `git status`
and the agents' reports). Companion to `REVISION_PLAN.md` and the
`REVISION_NOTES_P*.md` files. Nothing was fixed here except where stated (no code was
edited; one review artefact was written: this file). Style follows
`LIVE_ONLY_MIGRATION.md`.

## 0. Method

- Static checks on every script: `.find_analysis_dir()` block + `raw_path()/derived_path()/
  out_path()/fig_path()` helpers, no `setwd()`, no absolute paths, `set.seed()`, header
  block (WHAT/WHY/INPUTS/OUTPUTS/RUN), live-only sample and thresholds (inherited from
  `passer90.rda` or asserted), `_sampling_config.R` for brms models, Rubin pooling.
- Every fast path was **re-run by the reviewer** (R 4.6.0, same machine) after snapshotting
  all existing outputs, and each regenerated `.rds`/`.md`/derived file was compared with
  the agents' version (`all.equal`, tolerance 1e-6, timestamps and session slots stripped):
  `rebuild_passer90_live.R`, `audit_provenance.R`, `atlantic_multitrait.R`,
  `atlantic_bivariate_wing_mass.R --fast-lme4`, `atlantic_variance_sigma.R --fast`,
  `atlantic_diet_interaction.R --no-brms`, `atlantic_ants_index.R`,
  `climate_extraction.R`, `atlantic_drmsem.R --smoke`, `atlantic_parallel_controlled.R
  --fast-lme4`, and `quarto render index.qmd --to html` (with `_freeze/index` removed so
  every chunk re-executed).
- Every number quoted in a `REVISION_NOTES_P*.md` was checked against the regenerated
  `.rds`, and the agents' own run logs in the session scratchpad were read where the
  reports claimed results that had not been written to disk.
- Not re-run (as instructed): any brms/Stan tier, the full drmSEM, the diet brms path.

## 1. Bottom line

Everything reproduces **except Phase 1**. The provenance-controlled wing analysis
(`atlantic_parallel_controlled.R`) has a one-line bug that silently removes `Sex` from
every lme4 model fitted on the known-sex samples, so the script does not fit the models
it documents, and the numbers in `REVISION_NOTES_P1.md` (which *do* correspond to the
intended models) are not what the script writes. Details in §2.1. The decision-gate
conclusion (Scenario B) is unchanged either way, but several secondary statements flip
between the two versions, and downstream consumers (P6's `make_figures.R` export, P7)
must not read `controlled_wing_results.rds` until the script is fixed and re-run.

Two smoke tests reported as run (P1, P3) never finished; their notes need one sentence
each saying so. All other phases (P0, P2, P4a, P4ef, P5, P7) reproduce exactly.
